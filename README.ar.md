# بوت ديسكورد للروم الصوتي

**بوت ديسكورد قوي يبقى في الروم الصوتي على مدار الساعة ويرجع تلقائياً، مع نظام حدود طلبات ذكي حتى لا تعتبره ديسكورد سبام.**

## المميزات

- يدخل الروم الصوتي (أو روم المسرح) المحدد ويبقى فيه طوال الوقت
- يرجع تلقائياً عند الطرد أو الفصل أو النقل لروم ثاني
- نظام رجوع ذكي: تأخير تصاعدي مع عشوائية، وحد أقصى للمحاولات خلال فترة زمنية، وفترة تهدئة، لحماية البوت من حدود ديسكورد حتى لو أحد استمر بطرده
- إصلاح ذاتي: فحص دوري وربط بأحداث إعادة اتصال الجيتواي لالتقاط أي انقطاع صامت
- مضاد للكراش: كل المعالجات محمية بـ try/catch، وأخطاء `unhandledRejection` و `uncaughtException` تُسجَّل بدل ما توقف البوت
- إعادة محاولة تسجيل الدخول مع تأخير تصاعدي، وخروج نظيف عند الأخطاء القاتلة مثل التوكن الخاطئ
- إيقاف سليم عند `SIGINT` / `SIGTERM`
- ملف واحد، نظيف وسهل القراءة والتطوير
- جاهز لـ Docker و GitHub Actions

## المتطلبات

- Node.js إصدار 22.12 أو أحدث
- توكن بوت ديسكورد

## البدء السريع

### 1. إنشاء البوت

1. افتح [Discord Developer Portal](https://discord.com/developers/applications) وأنشئ تطبيقاً جديداً.
2. من تبويب **Bot** أنشئ البوت وانسخ التوكن.
3. لا تحتاج أي Privileged Intents.
4. ادعُ البوت لسيرفرك (بدّل `YOUR_CLIENT_ID`):

```
https://discord.com/oauth2/authorize?client_id=YOUR_CLIENT_ID&scope=bot&permissions=1049600
```

قيمة الصلاحيات `1049600` تمنح **View Channel** و **Connect**.

### 2. جلب المعرفات

فعّل **Developer Mode** من إعدادات ديسكورد (Advanced)، ثم كليك يمين على السيرفر والروم الصوتي واختر **Copy ID**.

### 3. التثبيت والتشغيل

```bash
git clone https://github.com/motaz-darawsha/discord-bot-afk.git
cd discord-bot-afk
npm install
cp .env.example .env
```

عبّي ملف `.env` ثم شغّل البوت:

```bash
npm start
```

## الإعدادات

| المتغير            | مطلوب | الافتراضي | الوصف                                  |
| ------------------ | ----- | --------- | -------------------------------------- |
| `DISCORD_TOKEN`    | نعم   | لا يوجد   | توكن البوت                             |
| `GUILD_ID`         | نعم   | لا يوجد   | معرف السيرفر                           |
| `VOICE_CHANNEL_ID` | نعم   | لا يوجد   | معرف الروم الصوتي أو روم المسرح        |
| `SELF_DEAF`        | لا    | `true`    | الدخول بوضع الصمم (اكتب `false` للتعطيل) |
| `SELF_MUTE`        | لا    | `false`   | الدخول بوضع الكتم (اكتب `true` للتفعيل)  |

لا ترفع ملف `.env` على GitHub أبداً، وهو مضاف أصلاً في `.gitignore`.

## سلوك الرجوع

| الحالة                                | تصرف البوت                                             |
| ------------------------------------- | ------------------------------------------------------ |
| طرد أو فصل من الروم                   | ينتظر مدة التأخير ثم يرجع                              |
| نقله لروم ثاني                        | يرجع للروم المحدد                                      |
| انقطاع الاتصال الصوتي                 | يحاول الاستعادة 5 ثواني ثم يعيد إنشاء الاتصال          |
| انقطاع الجيتواي ثم عودته              | الفحص الدوري والأحداث تتحقق وترجعه عند الحاجة          |
| الروم محذوف أو ممتلئ أو بدون صلاحيات  | يسجل السبب ويعيد المحاولة بتأخير متزايد                |
| طرد متكرر أو سبام                     | يزيد التأخير، وعند تجاوز الحد يدخل فترة تهدئة طويلة    |
| أي خطأ غير متوقع                      | يُسجَّل ويستمر البوت بالعمل                            |

### ضبط حدود الطلبات

القيم الافتراضية داخل الكائن `limits` في أعلى ملف `index.js`:

| الخيار             | الافتراضي | المعنى                                              |
| ------------------ | --------- | --------------------------------------------------- |
| `baseDelayMs`      | 3,000     | أول تأخير قبل الرجوع، ويتضاعف مع كل محاولة          |
| `maxDelayMs`       | 300,000   | أقصى تأخير للمحاولة الواحدة                         |
| `maxAttempts`      | 6         | عدد محاولات الرجوع المسموحة داخل النافذة الزمنية    |
| `windowMs`         | 600,000   | النافذة الزمنية لحساب المحاولات                     |
| `cooldownMs`       | 600,000   | فترة التهدئة عند بلوغ الحد الأقصى                   |
| `stableMs`         | 60,000    | مدة الاتصال المستقر قبل تصفير عداد التأخير          |
| `healthCheckMs`    | 30,000    | الفاصل الزمني للفحص الذاتي                          |
| `connectTimeoutMs` | 30,000    | مدة انتظار جاهزية الاتصال الصوتي                    |

## النشر

### Docker

```bash
cp .env.example .env
docker compose up -d --build
docker compose logs -f
```

### PM2

```bash
npm install -g pm2
pm2 start index.js --name discord-voice-bot --node-args="--env-file=.env"
pm2 save
```

## حل المشاكل

- **متغيرات بيئة ناقصة**: البوت يطبع أسماءها ويتوقف. راجع ملف `.env`.
- **الروم غير قابل للدخول**: أعطِ البوت صلاحيتي **View Channel** و **Connect** على الروم، وتأكد أنه غير ممتلئ.
- **خطأ قاتل عند تسجيل الدخول**: التوكن غير صالح. أعد توليده من Developer Portal وحدّث `.env`.
- **روم المسرح**: البوت يحاول يصير متحدثاً تلقائياً. إذا بقي مكتوماً، أعطه صلاحية **Mute Members** أو ادعه للتحدث يدوياً.
